Noket has three jobs, and most people only do one of them. Pick the path that matches yours.

| If you want to… | Start here | You need |
| --- | --- | --- |
| Call a model someone shared with you | [Use a shared model](/quickstarts/use-a-shared-model/) | A Noket account and an invitation |
| Share a model with other people | [Share your models](/quickstarts/share-your-models/) | A model, local or external |
| Share a model running on your machine | [Connect a local model](/quickstarts/connect-a-local-model/) | A machine running the connector and a local server |

Each path takes a few minutes. The pages under [Console](/console/), [API](/api/), and
[Connector](/connector/) go deeper once the first request works.
